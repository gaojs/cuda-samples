# matrixMulCUBLAS - Matrix Multiplication (CUBLAS)

## 描述

此示例实现《编程指南》第 3 章中的矩阵乘法。为展示 GPU 执行矩阵乘法的性能，示例还演示如何使用 CUDA 4.0 为 CUBLAS 引入的新接口，以实现高性能矩阵乘法。

## 核心概念

CUDA Runtime API, 性能策略, 线性代数, CUBLAS
