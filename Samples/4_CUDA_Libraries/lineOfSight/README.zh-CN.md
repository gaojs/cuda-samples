# lineOfSight - 视线

## 描述

此示例实现了一个简单的视线算法：给定一幅高度图和一条起点为观察点的射线，它会计算出沿射线从观察点可见的所有点。该实现基于 Thrust 库。

## 核心概念

Thrust 库
