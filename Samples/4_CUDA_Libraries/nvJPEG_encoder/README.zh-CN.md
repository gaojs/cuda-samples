# nvJPEG_encoder - NVJPEG Encoder

## 描述

一个 CUDA 示例，演示使用 NVJPEG 库对 JPEG 图像进行单张编码。

## 核心概念

图像编码, NVJPEG Library

## 支持的 SM 架构

## 支持的操作系统

Linux、Windows, QNX

## 支持的 CPU 架构

x86_64、aarch64

## 涉及的 CUDA API

### [CUDA Runtime API](http://docs.nvidia.com/cuda/cuda-runtime-api/index.html)
cudaFree, cudaGetErrorString, cudaEventSynchronize, cudaDeviceSynchronize, cudaEventRecord, cudaMalloc, cudaEventElapsedTime, cudaGetDeviceProperties, cudaEventCreate

## 构建/运行所需的依赖项
[NVJPEG](../../../README.md#nvjpeg)

## 前置条件

下载并安装适用于相应平台的 [CUDA Toolkit 12.5](https://developer.nvidia.com/cuda-downloads) 。
请确保已安装上文[依赖项]()部分中提到的依赖项。
