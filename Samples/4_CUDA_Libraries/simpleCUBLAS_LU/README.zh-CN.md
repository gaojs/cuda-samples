# simpleCUBLAS_LU - Simple CUBLAS LU

## 描述

CUDA 示例，演示 cuBLAS API cublasDgetrfBatched() 用于矩阵的下三角-上三角（LU）分解。

## 核心概念

CUBLAS 库, LU decomposition
