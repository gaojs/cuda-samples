# radixSortThrust - CUDA Radix Sort (Thrust 库)

## 描述

此示例演示如何使用 Thrust 库实现快速、高效的并行基数排序。示例中的 RadixSort 类既可对键值对（键为浮点数或无符号整数）排序，也可仅对键排序。

## 核心概念

数据并行算法, 性能策略
