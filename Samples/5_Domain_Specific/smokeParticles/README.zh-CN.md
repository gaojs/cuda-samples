# smokeParticles - 烟雾粒子

使用半角切片技术进行带体积阴影的烟雾模拟。使用 CUDA 进行程序化模拟，使用 Thrust 库 实现排序算法，并使用 OpenGL 进行图形渲染。

## 关键概念

图形互操作, 数据并行算法, 基于物理的模拟
