# quasirandomGenerator_nvrtc - 使用 libNVRTC 的 Niederreiter 准随机序列生成器

## 描述

此示例实现 Niederreiter 准随机序列生成器和逆累积正态分布函数，用于生成标准正态分布，并使用 NVRTC 在运行时编译所涉及的 CUDA kernel。

## 关键概念

Computational Finance, Runtime Compilation
