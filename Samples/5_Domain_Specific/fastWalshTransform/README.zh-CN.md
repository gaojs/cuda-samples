# fastWalshTransform - 快速 Walsh 变换

## 描述

自然（Hadamard）顺序的快速 Walsh 变换，用于批处理长度为 2 的幂且符合要求的任意长度向量。

## 核心概念

线性代数、数据并行算法、视频压缩
