# binomialOptions_nvrtc - 使用 libNVRTC 的二项式期权定价

## 描述

此示例使用二项式模型评估一组欧式期权的公平看涨期权价格。此示例使用 NVRTC 进行运行时编译。

## 核心概念

计算金融、运行时编译
