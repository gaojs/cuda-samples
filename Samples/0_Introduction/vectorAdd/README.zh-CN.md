# vectorAdd - 向量加法

## 描述

这是一个非常基础的 CUDA Runtime API 示例，实现逐元素向量加法。它与《编程指南》第 3 章中的示例相同，并增加了错误检查等内容。

## 关键概念

CUDA Runtime API, 向量加法
