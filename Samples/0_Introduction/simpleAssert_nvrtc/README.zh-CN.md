# simpleAssert_nvrtc - simpleAssert with libNVRTC

## 描述

这是一个非常基础的 CUDA Runtime API 示例，演示如何在设备代码中使用 assert 函数。需要 Compute Capability 2.0。

## 关键概念

Assert, 运行时编译
